SNS 로그인 / 계정 연동

로그인/연동 모두 SNS 토큰을 얻는 과정은 같고, 보내는 엔드포인트만 다릅니다. '연동'은 로그인된 상태에서만 가능합니다. 이미 같은 이메일의 계정이 있는데 SNS로 처음 로그인하면 서버가 409 (SOCIAL_EMAIL_CONFLICT)로 거절합니다 — 그 경우 기존 방식으로 로그인 후 '연동'을 쓰세요.
카카오 developers에 등록해야 하는 Redirect URI:
(플랫폼 Web 등록 + 카카오 로그인 활성화 + 위 Redirect URI 등록 필요. 보안 설정의 Client Secret은 '사용 안 함'이어야 합니다)
Google Cloud Console에서 '웹 애플리케이션' 타입 OAuth 클라이언트 ID를 만들고, 승인된 JavaScript 원본에 을 추가해야 합니다. (안드로이드용 클라이언트 ID는 웹에서 쓸 수 없습니다)
